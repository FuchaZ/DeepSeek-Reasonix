本版把会话互聊做到可用：全放行不再逐条拦互聊消息，跑着的轮次也能中途收到别的会话发来的话。工作台的页签现在能摸到每一个，内置浏览器加了页批注，工具调用里的图片不再需要展开整套调试面板才看得见。

## 新增

- 另一个会话发来的消息会在当前轮次中途送达，不再等整个任务跑完；走到的是和「插话」同一条通道，所以在下一个模型请求处生效，不是立刻打断 (e961f7ac0)
- 开了「完全放行」之后，互聊与派发这两类操作不再逐条弹卡；无人值守的 headless 会话仍然拒绝，这次放宽只覆盖交互式会话 (0df454a85)
- 会话把自己的角色与忙闲状态告诉对方，收到的消息卡片也写明发送方是干什么的、此刻是否在跑 (80bb44982、1911468b4、7b8a670fe)
- 回复可以点名它回的是哪一条，发送方也可以选择等一个回复 (7f3b15bb2)；一条消息的回复链条到第八跳为止，避免两个会话互相追问停不下来 (f56990695)
- 可以自己把任务交给另一个会话，不必等模型决定 (1201fa9d7)
- 互聊权限设为「从不」时，这个会话一条消息都不收 (d4404d519)
- 工作台的页签条能摸到每一个页签，关闭前的提示会说清它要关掉哪些 (50046d9f1)
- 内置浏览器可以给页面加批注，并多了一档冻结，页面跑起来时仍能读 (e40305217)
- 页面没有变化时，浏览器快照不再整份重复塞进模型上下文 (435c6dd17)
- 保存一个被声明为新文件的路径时直接创建它，不再报不存在 (7cc95881d)

## 变更

- 展示过图片的调用不再把整张卡连同调用 id、输入 JSON、结果回执一起摊开，图片直接画在那一行下面，随时可见；点开那一行才看细节，和别的调用一致 (8789ca825)
- 图片调用的名字与图标不再回落成英文的「View Image」和扳手；现在读「查看了图片」，图标是图片 (8789ca825)
- 缩略图去掉一段多余的左侧缩进，改成一行的样式：`contain` 不裁切、最高 104px、细边框、固定的底色，透明留白不会再像加载失败 (8789ca825、ff0715cfc)
- 很早的图片调用不会被「更早的 N 步」折叠吞掉，滚回去仍然看得见 (8789ca825)

## 修复

- 会话列表不再走进 `subagents/` 子树，侧栏里那些 `sa_` 开头的行不再出现 (4da06df36)
- 权限范围选择器里的每一项都写清它会写到哪里 (dcccb2cb9)
- 派发卡说明的是它自己的原因，不再借用项目列表的那句 (9890f438e)
- 派发到发送方自己的项目时弹卡询问，不再由一条规则直接放行 (843ce4498)
- 点「完全放行」时，屏幕上等着的卡一并结算；归属不明的卡会说清它没有被这次放行覆盖 (f4668e6c8、c7f92fb6d、08aebd3c6)
- 切换放行档位时按钮不会一直转圈等待 (a56ec9f55)
- 互聊与派发的卡片用读者的语言说明原因，不再回落到英文原文 (ff15945ae)
- 取消与回答同时到达时，那次回答仍然算数 (ef48cd756)
- 退出码与文件存在性这类内核拒绝补上了中文措辞 (0298a5533)
- 给另一个会话发消息前先问用户 (c5e97a769)

## 升级须知

- 已装 2.69.0 的直接装 2.69.1 覆盖；安装包文件名带版本号：`ReasonixStudio-windows-amd64-2.69.1-installer.exe` (https://github.com/FuchaZ/DeepSeek-Reasonix/releases)
- 安装包未签名，首次打开需要按系统提示放行 (https://github.com/FuchaZ/DeepSeek-Reasonix/releases)
- 互聊放宽只对交互式会话生效；以 headless 方式运行、无人值守的会话仍然拒绝对外发消息 (0df454a85)

This patch makes session-to-session messaging usable: full access no longer stops at every peer message, and a running turn takes a message from another session mid-task. The workbench strip reaches every tab, the browser gets page notes, and a call's picture stays visible.

## New

- A message from another session reaches a running turn instead of waiting for the whole task; it rides the same channel as a typed-in steer, so it lands at the next provider request rather than interrupting one (e961f7ac0)
- With full access on, peer messages and dispatches are no longer asked one by one; headless, unattended sessions still refuse, so the relaxation covers interactive sessions only (0df454a85)
- A session tells its peers what role it was opened for and whether it is busy, and a held message's card says the same about its sender (80bb44982, 1911468b4, 7b8a670fe)
- A reply can name the message it answers, and a sender may wait for one (7f3b15bb2); a chain of replies stops at eight hops so two sessions cannot keep answering each other (f56990695)
- A person can hand a task to another session themselves (1201fa9d7)
- Set to "never", a session takes no message at all (d4404d519)
- The tab strip reaches every tab, and its close prompt says what it will close (50046d9f1)
- The built-in browser takes page notes, and gains a freeze tier so a running page can still be read (e40305217)
- An unchanged page's snapshot is no longer sent to the model again in full (435c6dd17)
- A save whose revision says the file is new creates it instead of reporting a missing file (7cc95881d)

## Changed

- A call that showed a picture no longer unfolds its whole card — call id, input JSON and result receipt — to show it; the picture is drawn under the row and stays visible, and the row opens for details like any other call (8789ca825)
- A picture call is named and drawn by an image rather than falling back to "View Image" and a wrench icon (8789ca825)
- A thumbnail loses the stray left indent and reads as one line: contained rather than cropped, capped at 104px, a hairline border and a fixed ground, so a transparent letterbox no longer looks like a failed load (8789ca825, ff0715cfc)
- An old picture call is not swallowed by the "N earlier steps" count, so scrolling back still finds it (8789ca825)

## Fixed

- A folder's session listing no longer walks into its `subagents/` tree, so the `sa_` rows are gone from the sidebar (4da06df36)
- Each option in the scope picker names what it writes to (dcccb2cb9)
- The dispatch card states its own reason rather than borrowing the project list's (9890f438e)
- A dispatch into the sender's own project asks the card instead of a rule answering for it (843ce4498)
- Confirming full access settles the cards already on screen, and a card it does not cover says so (f4668e6c8, c7f92fb6d, 08aebd3c6)
- The posture switch can no longer leave the button that asked spinning (a56ec9f55)
- Peer and dispatch cards say why in the reader's language (ff15945ae)
- An answer that lands together with a cancel still counts as an answer (ef48cd756)
- Kernel refusals such as a missing file or a non-zero exit now have wording of their own (0298a5533)
- Telling another session asks the person first (c5e97a769)

## Upgrade notes

- Installing 2.69.1 over 2.69.0 replaces it; the installer carries its version in the name: `ReasonixStudio-windows-amd64-2.69.1-installer.exe` (https://github.com/FuchaZ/DeepSeek-Reasonix/releases)
- The installer is unsigned, so the first launch needs the system prompt allowed (https://github.com/FuchaZ/DeepSeek-Reasonix/releases)
- The peer relaxation covers interactive sessions only; a headless, unattended session still refuses to send (0df454a85)
