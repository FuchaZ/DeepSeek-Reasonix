This patch release rebuilds the kernel with go1.27.4, which fixes GO-2026-6859 — an HTTP/1 server crash in net/http that the shipped host carries.

## Changed

- The toolchain moves from go1.26.11 to go1.27.4, and the lint and govulncheck pins align (041129e78)

## Upgrade notes

- Installing 2.67.1 over 2.67.0 replaces it; the package names carry the version as before (https://github.com/FuchaZ/DeepSeek-Reasonix/releases)
