本版把 computer use 的驱动底座换到 0.59.0：拖拽进了后台动作清单，操作失败带上“下一步怎么做”的指引，测试不再往桌面弹窗口。

## 新增

- `computer_act` 新增 drag：在已授权应用窗口里后台拖拽——不抢指针、不抬窗口，两端坐标取自最新一次截图，固定左键；起点被盖住或拖标题栏这类 OS 不允许后台完成的场景直接拒绝，永不升级前台 (45bb12cfd)
- 被拒绝或效果未验证的操作带驱动的恢复指引：一句有界的“下一步怎么做”和它点名的下一个调用（只渲染，host 从不代跑）；拒绝自身的原因与指引分开，读取按 0.59.0 实测的扁平契约（code、prose、hint、next_call 都在顶层）(45bb12cfd)

## 变更

- 驱动底座从 0.34.1 换到 0.59.0：Windows 按活动键盘布局精确打字（否则拒绝）、不可用截图的 WARP 回退、密码框 is_password 标记、Chromium 屏幕范围修正等上游六周修复随包更新；快照显式请求 `tree_format=elements`——0.59.0 默认返回 markdown 树，不带参数快照会静默为空 (30e2b19f7)
- 内嵌驱动契约升到 0.9.0（tools-list、capability 与 MCP 协议字段不变），五个平台 artifact 的 SHA-256 按上游 release 校验 (30e2b19f7)

## 修复

- Windows 上跑 builtin 测试不再弹出 120 秒的 PowerShell 窗口：取消用例的 Start-Process 加 -WindowStyle Hidden，取消语义不变 (8f6547e87)
- 本地打包命令表补上安装包版本号命名覆盖（与 release-fork.yml 一致），照文档跑不再产出无版本名的包 (bfd5155f0)

The computer use driver moves to 0.59.0: drag joins the background action catalogue, refused or unverifiable steps carry the driver's next-step guidance, and the test suite stops opening a console window on the desktop.

## New

- `computer_act` advertises drag: a background drag that never takes the pointer, endpoints from the latest screenshot, left button; a covered start point or a caption drag refuses without escalating to the foreground. Refused and unverifiable steps also carry the driver's recovery hint — one bounded sentence plus the exact call it names, rendered for the model and never executed, with the refusal's own reason kept apart (45bb12cfd)

## Changed

- The pinned CUA Driver moves from 0.34.1 to 0.59.0: Windows types exactly on the active keyboard layout or refuses, a WARP fallback for unusable captures, is_password on password fields, corrected Chromium extents; snapshots ask for tree_format=elements explicitly, since 0.59.0 defaults to a markdown tree and a bare call read back empty (30e2b19f7)
- The embedded contract moves to 0.9.0 with all five platform digests re-pinned to the upstream release (30e2b19f7)

## Fixed

- The cancel test's Start-Process takes -WindowStyle Hidden; the suite stops opening a console window (8f6547e87)

## Upgrade notes

- Names carry the version: `ReasonixStudio-windows-amd64-2.67.0-installer.exe` / `-portable.zip`; both unsigned, SmartScreen asks on first run (https://github.com/FuchaZ/DeepSeek-Reasonix/releases)
