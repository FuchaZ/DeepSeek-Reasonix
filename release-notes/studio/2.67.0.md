本版把 computer use 的驱动底座整体换到 0.59.0，拖拽进了后台动作清单，操作失败时带上“下一步怎么做”的指引；测试不再往桌面弹窗口。

## 新增

- `computer_act` 的动作清单新增 drag：在已授权应用的窗口里后台拖拽——不抢指针、不抬窗口，两端坐标都取自最新一次截图，固定左键；起点被别的窗口盖住或拖标题栏这类 OS 不允许后台完成的场景直接拒绝，并且永不升级前台 (45bb12cfd)
- 操作被拒绝或效果未能验证时，结果带驱动的恢复指引：一句有界的“下一步怎么做”，和它点名的下一个调用（只渲染给模型看，host 从不代跑）；拒绝自身的原因与下一步指引严格分开，理由不再被指引顶替 (45bb12cfd)
- 拒绝理由的读取按 0.59.0 的实测形状走扁平契约（code、prose、hint、next_call 都在顶层），拒绝理由与指引同屏但不混用 (45bb12cfd)

## 变更

- computer use 的驱动底座从 0.34.1 换到 0.59.0：上游六周约 25 个 minor、百余项修复随包更新——Windows 按活动键盘布局精确打字（否则拒绝）、不可用截图的 WARP 回退、密码框 is_password 标记、Chromium 屏幕范围修正等 (30e2b19f7)
- 内核读窗口快照显式请求 `tree_format=elements`：0.59.0 的 `get_window_state` 默认改返回 markdown 树，不带这个参数快照会静默为空 (30e2b19f7)
- 内嵌驱动契约升到 0.9.0（tools-list、capability 与 MCP 协议字段不变），五个平台的 artifact 名与 SHA-256 全部按上游 release 校验；Electron 就绪门禁与安装脚本的认领 stamp 跟随新版本 (30e2b19f7)
- 拒绝理由的边界裁剪并入仓库统一的 grapheme 惯用做法（2048 字素 + 省略号），多字节理由不再有第二套字节裁剪 (45bb12cfd)

## 修复

- Windows 上跑 builtin 测试不再弹出一个 120 秒的 PowerShell 窗口：取消用例的 `Start-Process` 加 `-WindowStyle Hidden`，取消语义不变 (8f6547e87)
- 本地打 Windows 安装包的命令表补上版本号命名覆盖（与 release-fork.yml 一致），照文档跑不会再产出无版本名的安装包 (bfd5155f0)

## 升级须知

- Windows 的安装包与便携包文件名带版本号：`ReasonixStudio-windows-amd64-2.67.0-installer.exe` 与 `ReasonixStudio-windows-amd64-2.67.0-portable.zip`，同机留几个版本也分得清 (https://github.com/FuchaZ/DeepSeek-Reasonix/releases)
- 便携包是 zip，解压即用，不需要管理员权限；安装包与便携包里是同一个应用，任选其一 (https://github.com/FuchaZ/DeepSeek-Reasonix/releases)
- 两个包都未签名，首次打开需要按系统提示放行 (https://github.com/FuchaZ/DeepSeek-Reasonix/releases)
- 更新检查仍指向原项目的目录，版本面板可能提示一个更新的版本 (https://github.com/FuchaZ/DeepSeek-Reasonix)

This release moves the computer use driver to 0.59.0, adds background drag to the advertised action catalogue, and carries the driver's recovery hints on refusals and unverifiable results.

## Added

- `computer_act` advertises drag: a background drag inside an approved application's window — it never takes the person's pointer, both endpoints come from the latest screenshot with the left button, and a covered start point or a caption drag refuses without ever escalating to the foreground (45bb12cfd)
- A refused or unverifiable step carries the driver's recovery hint: one bounded next-step sentence and the exact call it names, rendered for the model and never executed by the host; the refusal's own reason stays apart from that guidance (45bb12cfd)

## Changed

- The pinned CUA Driver moves from 0.34.1 to 0.59.0: six weeks of upstream fixes — Windows types exactly on the active keyboard layout or refuses, a WARP fallback for unusable captures, is_password on Edit elements, corrected Chromium screen extents (30e2b19f7)
- `get_window_state` asks for `tree_format=elements` explicitly: 0.59.0 defaults to a markdown tree, and without it a snapshot reads back empty (30e2b19f7)
- The embedded driver contract moves to 0.9.0 (tools-list, capability and MCP protocol fields unchanged), with all five platform artifacts pinned to the upstream release digests (30e2b19f7)

## Fixed

- Running the builtin tests on Windows no longer opens a 120-second PowerShell window: the cancel test's `Start-Process` takes `-WindowStyle Hidden` (8f6547e87)

## Upgrade notes

- The Windows installer and portable archive carry the version in their file names: `ReasonixStudio-windows-amd64-2.67.0-installer.exe` and `ReasonixStudio-windows-amd64-2.67.0-portable.zip` (https://github.com/FuchaZ/DeepSeek-Reasonix/releases)
- Both packages are unsigned; SmartScreen asks on first run (https://github.com/FuchaZ/DeepSeek-Reasonix/releases)
