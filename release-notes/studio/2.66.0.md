This revision shows a delivered picture as a picture, finds the file a path written from a
subdirectory names, and repairs where the settings sheet lands and what the plan's badge counts;
Windows' two packages carry their version in the file name from this release on.

## New

- A picture a reply delivers draws above its file row, and a click opens the shared zoom viewer; a load that fails drops the picture and leaves the row as it was (3e9ac14)
- A link written from a subdirectory (a crate next door's `target/release/app.exe`) opens: a read that finds nothing matches the written suffix under the authorized roots, an ambiguous match says so instead of picking one, and a remote kernel is never asked because its paths name another machine's disk (3e9ac14)
- The default model gains 跟随最后一次选择: pick it and the default follows whatever the composer last chose instead of staying on one model (78b1b55)
- A browser tab is named by the page's own title, following a script that sets it and a route change that sets it again, instead of staying on the address (78b1b55)
- Guidance sent mid-turn can carry an image, and it arrives with the sentence it belongs to (78b1b55)
- The settings sheet comes back to the page it was left on: remembered per window, so a second window keeps its own, and a first visit still lands on 常用 (6b43eaa)
- A request names the conversation it belongs to for the gateway: sampling, command triage and title generation carry the session's transcript branch id, which the gateway strips before the vendor sees it (48c2c3f)
- Another session finds this one by its title — the custom title or the topic that was written for it, falling back to the branch id only when it has no name (48c2c3f)

## Changed

- Settings opens on a page that was named for it (a search result, a chip, a panel's own entry), then on the section this window last read, then on 常用 (6b43eaa)
- Opening a long conversation no longer decodes every superseded snapshot and then decodes the log again; it starts at the newest one and reuses the load the opener already took (78b1b55)
- The new-project and rename-project cards share one placement rule, and both stay inside the viewport at any zoom (600c877)
- A phase and its sub-steps are drawn as two depths: a sub-step's mark drops its ring and a size, instead of leaning on an indent alone (08eff20)

## Fixed

- The project pill stands above the composer on the composer's left edge instead of being pushed into an implicit bottom row (2cfafd2)
- A `/` written at the start of a line is asked about standing alone, so the whole catalogue comes back; one in the middle of a line stays a chip (34c350b)
- The plan's badge names the phase a person counts to, so a card no longer reads "第 7 步" while pointing at row 5 (08eff20)
- A conversation row's hover card yields to the row menu it covers: right click, the row's ⋯ and Shift+F10 all pass through one state, and the card returns on the next hover once the menu closes (3dda954)
- The rename-project card is a card again rather than a block cut off inside the clipped column, and no blank strip shows under its field (600c877)

## Upgrade notes

- Windows' installer and portable package carry their version in the file name from this release on — `ReasonixStudio-windows-amd64-2.66.0-installer.exe` and `ReasonixStudio-windows-amd64-2.66.0-portable.zip` — so several versions on one machine stay apart (https://github.com/FuchaZ/DeepSeek-Reasonix/releases)
- The portable package is a zip: unpack and run, with no administrator rights needed; it is the same app as the installer, so take either one (https://github.com/FuchaZ/DeepSeek-Reasonix/releases)
- Both packages are unsigned, so the first launch needs the system prompt let through (https://github.com/FuchaZ/DeepSeek-Reasonix/releases)
- The update check still points at the original project's catalog, so the versions panel may offer its newer build (https://github.com/FuchaZ/DeepSeek-Reasonix)
