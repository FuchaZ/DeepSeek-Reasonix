本版汇总 2.69.3 以来的改动：左栏与工作台的开合动效和长会话掉帧修复、思考流的匀速显示、回复中的 shell 命令直接在工作台终端运行、侧栏会话的一键折叠，以及派发会话的任务保留修复。

## 新增

- 回复中的 shell 代码块多了一个运行按钮：命令会送到同族的空闲终端（没有就新开一个），正在跑命令的终端不会被写入，模型输出里的控制字符会先被剔除；工作台同时切到那个终端页签 (153e4fd13)
- 侧栏「任务列表」标题行多了一个按钮：一键收起或展开所有本地项目文件夹的会话；项目、任务、远程项目和它们各自的 run 都有 180ms 折叠动画，收起后行从 DOM 移除 (1d26102fe)

## 变更

- 左栏改成覆盖在阅读列上的滑出层，开合不再重排会话树；150 轮的长会话下，左栏与右工作台的切换不再掉帧 (a47848545)
- 左栏、图标栏、页签条和右工作台统一使用抽屉缓动：图标栏不再瞬移 48px，页签条不再被左栏盖住，工作台只做一次列宽过渡 (45c263d79、d894c2863、4f75a2c88)
- 思考内容按到达速度匀速显示，最多领先 0.4 秒并在约 120ms 内追上；折叠预览也走同一节奏 (509a93804)
- 手机端：系统返回键先关闭页面自己的层（设置、菜单、抽屉、悬浮卡、工作台、预览），只有无人处理时才离开页面；状态栏/挖孔/键盘 insets、触控目标与安全区一并调整，行内公式不再溢出所在行 (d79b03cc8)
- 横屏下左上角的栏开关不再落在状态栏下面，点击不会被状态栏吃掉 (54ba2e0d7)
- Android 版本同步到 2.70.0（debug 包版本 2.70.0-debug，versionCode 27001） (8a48f7315)

## 修复

- 派发出去的会话会保留它被打开时要做的那件事：合成回合算作会话主题，不再在列表里消失、退出时被清掉；已落盘的零回合会话会在下次列出时重新推导，取消与崩溃恢复也保留开场回合 (2fee3f1ff)
- 停止进程时不再留下每个 state 目录一个的 dispatcher goroutine，长时间运行或反复建目录时不再泄漏 (3ed625ec3)
- 测试与 CI：`internal/frontend/serve` 的测试分成三片并行（`make test-serve`，本机约 5 分钟），隔离 home 目录在退出时清理 (d9bf2469e、3f03ea2f4)

This release gathers everything since 2.69.3: the rail and workbench motion and long-transcript jank fixes, an even-paced thinking stream, a run action for shell blocks in replies, one-click session folding in the sidebar, and the fix that keeps a dispatched session's opening task.

## New

- A shell block in a reply gains a run action: the command goes to an idle terminal of the same shell family (a new one is opened when needed), a busy terminal is never typed into, control characters in model output are stripped, and the workbench switches to that terminal tab (153e4fd13)
- The task-list header gains a control that folds or expands every local project's sessions at once; the two runs, local projects and remote projects all animate their fold over 180ms, and rows leave the DOM once closed (1d26102fe)

## Changed

- The workspace rail is now an overlay that slides over the reading column instead of reflowing it, and a fold no longer recalculates the conversation; toggling the rail and the workbench on a 150-turn session no longer drops frames (a47848545)
- The rail, icon column, session tab strip and workbench share the drawer curve: the icon column no longer jumps 48px, the tab strip no longer sits under the rail, and the workbench tweens its column once (45c263d79, d894c2863, 4f75a2c88)
- Thinking text is revealed at its arrival rate, leading by at most 0.4s and catching up within about 120ms; the folded preview uses the same pace (509a93804)
- On phones, the system back gesture now closes the page's own layers (settings, menus, drawer, hover cards, workbench, previews) and only leaves when nothing handles it; status-bar/cutout/keyboard insets, touch targets and safe areas were aligned, and inline formulas no longer overflow their line (d79b03cc8)
- In landscape, the rail toggle no longer sits under the status bar, so its press is not consumed by the system bar (54ba2e0d7)
- Android builds now carry 2.70.0 (debug package 2.70.0-debug, versionCode 27001) (8a48f7315)

## Fixed

- A dispatched session keeps the task it was opened to do: its synthetic host turn counts as the session subject, so it no longer disappears from the list or loses its opening turn on exit; zero-turn sessions already on disk are re-derived on their next listing, and cancel/crash recovery preserve the opening turn (2fee3f1ff)
- Stopping a process no longer leaves one dispatcher goroutine per state directory, so long-running processes and repeated directory creation no longer leak (3ed625ec3)
- Tests and CI: `internal/frontend/serve` is split into three parallel shards (`make test-serve`, about 5 minutes locally), and the isolated home directory is removed on exit (d9bf2469e, 3f03ea2f4)

## Upgrade notes

- No other release was published after 2.69.3; installing this version replaces it, and the installer carries its version in the name: `ReasonixStudio-windows-amd64-2.70.0-installer.exe` (https://github.com/FuchaZ/DeepSeek-Reasonix/releases)
- The portable build is also shipped: `ReasonixStudio-windows-amd64-2.70.0-portable.zip` (https://github.com/FuchaZ/DeepSeek-Reasonix/releases)
- The installer is unsigned, so the first launch needs the system prompt allowed (https://github.com/FuchaZ/DeepSeek-Reasonix/releases)
