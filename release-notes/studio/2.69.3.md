本版收尾 2.69.2 的工具调用合并：修掉它带进来的排版与归属问题，让另一个会话送来的消息在对话里留下痕迹；停靠工作台时窗口按钮失效和依赖里的一个 WebSocket 安全公告也一并处理。

## 新增

- 另一个会话的消息经你放行后，会话里会留下一条「来自另一个会话：<发送者>」的提示，重开会话仍在；不再只让对话悄悄改变走向 (13fb649c8)

## 变更

- 给模型的 `list_peers` / `send_peer_message` 说明改为如实描述：对端在下一个模型请求就会读到消息，会话正在跑也会中途注入，不再说「等这一轮结束」 (4ed970c9b)
- 一串命令合成一行后，每条命令仍保留自己的锚点与完整输出读回；成功但没有输出的命令仍把命令显示在正文里；后台启动仍是一行，并指向它的任务入口 (4ed970c9b)

## 修复

- 工作台停靠时，最小化/最大化/关闭三个窗口按钮被页签槽位罩住，点了没有反应；槽位现在停在按钮左沿 (de444bb17)
- 关闭通知总开关后，从属设置行的整行半透明把文字稀释到 AA 以下（浅色 2.66、深色 2.32）；现在只把标签降到 `--muted` (75dce43e8)
- 展开一条成组命令的输出时，整行被撑到内容宽度（2101px 对 677px 的卡片）；输出现在按组宽换行并在内部横向滚动 (76a5e517a)
- 390px 窄窗口、1.3 倍字号下，四段式选择器撑出设置卡片 43px；现在按行宽收缩并换行 (76a5e517a)
- 另一个会话的 steer 消息在重开会话后被算成用户自己说的插话；现在按 host-authored 呈现，桌面与 TUI 一致 (4ed970c9b)
- 分组里的失败分支与计数、审批方式选择的 id 比较、成本计时的清理、隐藏工作台时未关的菜单、页签条移动时丢失的重命名草稿、全屏切换后的焦点、TUI 的 YOLO 提示等批次回归 (4ed970c9b)
- `gorilla/websocket` 的 mask key 改用 crypto/rand：GO-2026-6278 尚无正式发布版本，升到公告指名的修复 commit，`govulncheck` 报 0 (0e5345afb)

This release finishes 2.69.2's tool-call grouping: it closes the layout and attribution problems that came with it, and leaves a visible trace when another session speaks. The window controls losing their presses while the workbench is docked, and a WebSocket advisory in a dependency, are fixed as well.

## New

- When another session's message is released to you, the conversation keeps a "message from another session: <sender>" notice, and reopening the session still shows it; the transcript no longer changes course silently (13fb649c8)

## Changed

- `list_peers` / `send_peer_message` now tell the model the truth: the peer reads the message at its next model request, mid-turn if that session is working, instead of "when the turn ends" (4ed970c9b)
- A grouped command keeps its own anchor and full-output read-back; a successful command with no output still shows its command in the body; a background start stays a row that leads to its job entry (4ed970c9b)

## Fixed

- With the workbench docked, minimise, maximise and close lost their presses to the tab-strip slot; the slot now ends at their left edge (de444bb17)
- With notifications switched off, the whole off branch faded its text below AA (2.66 light, 2.32 dark); the label now steps down to `--muted` instead (75dce43e8)
- Opening a grouped command's output stretched the row to the content's width (2101px against a 677px card); the output now takes the group's width and scrolls inside it (76a5e517a)
- At a 390px window with 1.3× text, a four-option segmented control pushed 43px out of its settings card; it now shrinks to the row and wraps (76a5e517a)
- A peer steer was counted as the person's own message after reopening the session; it is host-authored now, in the desktop and the TUI alike (4ed970c9b)
- Batch regressions around the grouping: dead failure branches and counts, the approval-mode id comparison, the cost timer cleanup, a menu left open when the workbench hides, the rename draft lost when the strip moves, focus after a full toggle, and the TUI's YOLO notice (4ed970c9b)
- `gorilla/websocket` derives its mask key from crypto/rand: GO-2026-6278 has no released fix, so the module moves to the fix commit the advisory names; `govulncheck` reports 0 (0e5345afb)

## Upgrade notes

- Installing 2.69.3 over 2.69.x replaces it; the installer carries its version in the name: `ReasonixStudio-windows-amd64-2.69.3-installer.exe` (https://github.com/FuchaZ/DeepSeek-Reasonix/releases)
- This release ships the installer only; there is no portable build (https://github.com/FuchaZ/DeepSeek-Reasonix/releases)
- The installer is unsigned, so the first launch needs the system prompt allowed (https://github.com/FuchaZ/DeepSeek-Reasonix/releases)
