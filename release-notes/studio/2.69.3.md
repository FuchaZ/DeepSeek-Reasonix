本版是自 2.67.1 以来的一次汇总发布：会话互聊、工作台页签、内置浏览器页批注、图片与工具调用的合并展示，以及 2.69.3 的收尾修复，全部包含在内。2.67.1 之后没有单独发布过 2.68 与 2.69 的中间版本，直接安装本版即可补齐。

## 新增

- 另一个会话发来的消息会在当前轮次中途送达，不再等整个任务跑完；走到的是和「插话」同一条通道，所以在下一个模型请求处生效，不是立刻打断 (e961f7ac0)
- 开了「完全放行」之后，互聊与派发这两类操作不再逐条弹卡；无人值守的 headless 会话仍然拒绝，这次放宽只覆盖交互式会话 (0df454a85)
- 会话把自己的角色与忙闲状态告诉对方，收到的消息卡片也写明发送方是干什么的、此刻是否在跑 (80bb44982、1911468b4、7b8a670fe)
- 回复可以点名它回的是哪一条，发送方也可以选择等一个回复 (7f3b15bb2)；一条消息的回复链条到第八跳为止，避免两个会话互相追问停不下来 (f56990695)
- 可以自己把任务交给另一个会话，不必等模型决定 (1201fa9d7)
- 互聊权限设为「从不」时，这个会话一条消息都不收 (d4404d519)
- 另一个会话的消息经你放行后，会话里会留下一条「来自另一个会话：<发送者>」的提示，重开会话仍在；不再只让对话悄悄改变走向 (13fb649c8)
- 工作台的页签条能摸到每一个页签，关闭前的提示会说清它要关掉哪些 (50046d9f1)
- 内置浏览器可以给页面加批注，并多了一档冻结，页面跑起来时仍能读 (e40305217)
- 页面没有变化时，浏览器快照不再整份重复塞进模型上下文 (435c6dd17)
- 保存一个被声明为新文件的路径时直接创建它，不再报不存在 (7cc95881d)

## 变更

- 展示过图片的调用不再把整张卡连同调用 id、输入 JSON、结果回执一起摊开，图片直接画在那一行下面，随时可见；点开那一行才看细节，和别的调用一致 (8789ca825)
- 图片调用的名字与图标不再回落成英文的「View Image」和扳手；现在读「查看了图片」，图标是图片 (8789ca825)
- 缩略图去掉一段多余的左侧缩进，改成一行的样式：`contain` 不裁切、最高 104px、细边框、固定的底色，透明留白不会再像加载失败 (8789ca825、ff0715cfc)
- 很早的图片调用不会被「更早的 N 步」折叠吞掉，滚回去仍然看得见 (8789ca825)
- 连续的 `view_image` 合成一行「查看图片 N 张」，N 张缩略图并排，每张仍带自己的文件路径，点开仍是大图 (ff0715cfc)
- 连续的 `bash` 合成一行「运行命令 N 条」，每条命令各占一行，点开能看完整命令和它的输出，也能把结果带到末尾 (ff0715cfc)
- 只有结束的调用参与合并：失败的要显示退出码，运行中的是读者正在等的那条，后台任务保留自己的状态入口，三者都独立成行 (ff0715cfc)
- 一次调用不成组：单张图、单条命令仍是原来的卡片，不额外加一层标题 (ff0715cfc)
- 「执行过程」此前遇到图片会无视折叠设置强行展开，现在按设置来；收起时在组头上写明它持有什么 (ff0715cfc)
- 一条 shell 命令的行不再裁成 96 字符的半句话，改说它运行了一条命令；完整命令在展开后的输入里 (5ecafc8df)
- 给模型的 `list_peers` / `send_peer_message` 说明改为如实描述：对端在下一个模型请求就会读到消息，会话正在跑也会中途注入，不再说「等这一轮结束」 (4ed970c9b)
- 一串命令合成一行后，每条命令仍保留自己的锚点与完整输出读回；成功但没有输出的命令仍把命令显示在正文里；后台启动仍是一行，并指向它的任务入口 (4ed970c9b)

## 修复

- 会话列表不再走进 `subagents/` 子树，侧栏里那些 `sa_` 开头的行不再出现 (4da06df36)
- 权限范围选择器里的每一项都写清它会写到哪里 (dcccb2cb9)
- 派发卡说明的是它自己的原因，不再借用项目列表的那句 (9890f438e)
- 派发到发送方自己的项目时弹卡询问，不再由一条规则直接放行 (843ce4498)
- 点「完全放行」时，屏幕上等着的卡一并结算；归属不明的卡会说清它没有被这次放行覆盖 (f4668e6c8、c7f92fb6d、08aebd3c6)
- 切换放行档位时按钮不会一直转圈等待 (a56ec9f55)
- 互聊与派发的卡片用读者的语言说明原因，不再回落到英文原文 (ff15945ae)
- 取消与回答同时到达时，那次回答仍然算数 (ef48cd756)
- 退出码与文件存在性这类内核拒绝补上了中文措辞 (0298a5533)
- 给另一个会话发消息前先问用户 (c5e97a769)
- 正在运行的调用换了会话再回来，计时不再从头开始 (d1e65859e)
- 工作台停靠时，最小化/最大化/关闭三个窗口按钮被页签槽位罩住，点了没有反应；槽位现在停在按钮左沿 (de444bb17)
- 关闭通知总开关后，从属设置行的整行半透明把文字稀释到 AA 以下（浅色 2.66、深色 2.32）；现在只把标签降到 `--muted` (75dce43e8)
- 展开一条成组命令的输出时，整行被撑到内容宽度（2101px 对 677px 的卡片）；输出现在按组宽换行并在内部横向滚动 (76a5e517a)
- 390px 窄窗口、1.3 倍字号下，四段式选择器撑出设置卡片 43px；现在按行宽收缩并换行 (76a5e517a)
- 另一个会话的 steer 消息在重开会话后被算成用户自己说的插话；现在按 host-authored 呈现，桌面与 TUI 一致 (4ed970c9b)
- 分组里的失败分支与计数、审批方式选择的 id 比较、成本计时的清理、隐藏工作台时未关的菜单、页签条移动时丢失的重命名草稿、全屏切换后的焦点、TUI 的 YOLO 提示等批次回归 (4ed970c9b)
- `gorilla/websocket` 的 mask key 改用 crypto/rand：GO-2026-6278 尚无正式发布版本，升到公告指名的修复 commit，`govulncheck` 报 0 (0e5345afb)

<!-- lang:en -->

This release gathers everything since 2.67.1: peer messaging, the workbench strip, browser page notes, picture and command rows, and the 2.69.3 fixes. No 2.68 or 2.69 was published in between.

## New

- A message from another session reaches a running turn instead of waiting for the whole task; it rides the same channel as a typed-in steer, so it lands at the next provider request rather than interrupting one (e961f7ac0)
- With full access on, peer messages and dispatches are no longer asked one by one; headless, unattended sessions still refuse, so the relaxation covers interactive sessions only (0df454a85)
- A session tells its peers what role it was opened for and whether it is busy, and a held message's card says the same about its sender (80bb44982, 1911468b4, 7b8a670fe)
- A reply can name the message it answers, and a sender may wait for one (7f3b15bb2); a chain of replies stops at eight hops so two sessions cannot keep answering each other (f56990695)
- A person can hand a task to another session themselves (1201fa9d7)
- Set to "never", a session takes no message at all (d4404d519)
- When another session's message is released to you, the conversation keeps a "message from another session: <sender>" notice, and reopening the session still shows it; the transcript no longer changes course silently (13fb649c8)
- The tab strip reaches every tab, and its close prompt says what it will close (50046d9f1)
- The built-in browser takes page notes, and gains a freeze tier so a running page can still be read (e40305217)
- An unchanged page's snapshot is no longer sent to the model again in full (435c6dd17)
- A save whose revision says the file is new creates it instead of reporting a missing file (7cc95881d)

## Changed

- A call that showed a picture no longer unfolds its whole card — call id, input JSON and result receipt — to show it; the picture is drawn under the row and stays visible, and the row opens for details like any other call (8789ca825)
- A picture call is named and drawn by an image rather than falling back to "View Image" and a wrench icon (8789ca825)
- A thumbnail loses the stray left indent and reads as one line: contained rather than cropped, capped at 104px, a hairline border and a fixed ground, so a transparent letterbox no longer looks like a failed load (8789ca825, ff0715cfc)
- An old picture call is not swallowed by the "N earlier steps" count, so scrolling back still finds it (8789ca825)
- Consecutive `view_image` calls become one "Viewed N images" row; the thumbnails sit side by side, each still naming its own file, and each still opens full size (ff0715cfc)
- Consecutive `bash` calls become one "Ran N commands" row; each command is its own line and opens to the whole command and its output (ff0715cfc)
- Only finished calls take part: a failed one keeps the row that shows its exit status, a running one is what the reader is waiting on, and a background start keeps the row that leads to its output (ff0715cfc)
- A single call is not a group: one picture or one command stays the card it was, with no heading above it (ff0715cfc)
- The execution group obeys the reader's folding preference; folded, it says on its own line what it holds (ff0715cfc)
- A shell row no longer shows the command clipped at 96 characters; it says a command ran, and the whole command is in the body (5ecafc8df)
- `list_peers` / `send_peer_message` now tell the model the truth: the peer reads the message at its next model request, mid-turn if that session is working, instead of "when the turn ends" (4ed970c9b)
- A grouped command keeps its own anchor and full-output read-back; a successful command with no output still shows its command in the body; a background start stays a row that leads to its job entry (4ed970c9b)

## Fixed

- A folder's session listing no longer walks into its `subagents/` tree, so the `sa_` rows are gone from the sidebar (4da06df36)
- Each option in the scope picker names what it writes to (dcccb2cb9)
- The dispatch card states its own reason rather than borrowing the project list's (9890f438e)
- A dispatch into the sender's own project asks the card instead of a rule answering for it (843ce4498)
- Confirming full access settles the cards already on screen, and a card it does not cover says so (f4668e6c8, c7f92fb6d, 08aebd3c6)
- The posture switch can no longer leave the button that asked spinning (a56ec9f55)
- Peer and dispatch cards say why in the reader's language (ff15945ae)
- An answer that lands together with a cancel still counts as an answer (ef48cd756)
- Kernel refusals such as a missing file or a non-zero exit now have wording of their own (0298a5533)
- Telling another session asks the person first (c5e97a769)
- A running call's timer no longer restarts when a session switch draws the pane again (d1e65859e)
- With the workbench docked, minimise, maximise and close lost their presses to the tab-strip slot; the slot now ends at their left edge (de444bb17)
- With notifications switched off, the whole off branch faded its text below AA (2.66 light, 2.32 dark); the label now steps down to `--muted` instead (75dce43e8)
- Opening a grouped command's output stretched the row to the content's width (2101px against a 677px card); the output now takes the group's width and scrolls inside it (76a5e517a)
- At a 390px window with 1.3× text, a four-option segmented control pushed 43px out of its settings card; it now shrinks to the row and wraps (76a5e517a)
- A peer steer was counted as the person's own message after reopening the session; it is host-authored now, in the desktop and the TUI alike (4ed970c9b)
- Batch regressions around the grouping: dead failure branches and counts, the approval-mode id comparison, the cost timer cleanup, a menu left open when the workbench hides, the rename draft lost when the strip moves, focus after a full toggle, and the TUI's YOLO notice (4ed970c9b)
- `gorilla/websocket` derives its mask key from crypto/rand: GO-2026-6278 has no released fix, so the module moves to the fix commit the advisory names; `govulncheck` reports 0 (0e5345afb)
