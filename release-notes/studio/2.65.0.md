本版把 Oliver-Rui fork（`DeepSeek-Reasonix-torch`）里属于本树的部分整体搬了过来：侧边栏改成两个常驻分组、一套拖拽，
新增时间线读法、新会话项目药丸、消息时间与派发 chip；设置页按「回答什么问题」重新归位，Android 壳的工程进入仓库。

## 新增

- 侧边栏分成「项目」与「任务」两组，各组标题自己折叠自己那一组，标题右端是它那一组的添加入口 (159861c)
- 拖动项目、分组标题、会话行共用一条插入线；邻近行按拖动方向翻边，画出的线永远等于会发生的位置移动 (159861c)
- 「任务列表」左侧的时钟把列表切成按日期分组的时间线，每个会话一行、右侧是相对日期 (159861c)
- 新会话不再在空转录里问项目，改由输入框上方的项目药丸指定（含搜索、空项目新建） (159861c)
- 每条回复带上它落定的时间，悬停才显示，开关在 设置 → 对话显示 → 消息时间 (0f7226c)
- 模型来源的「刷新模型」会重新读端点列表，把端点自报的显示名填成空别名；厂商图标增到 37 个 (0f7226c)
- meter rail 上的会话互聊 chip 汇总本会话派发出去的任务，悬停展开每条的状态，可直接跳到落地会话 (2ad7fb3)
- 设置里的「跨项目派发」三档：始终允许（默认）、配对允许（只给已在那个项目打开的窗格）、禁止 (2ad7fb3)
- 设置新增「会话互聊」独立一页：派发链深度、单轮派发给几个会话、引用上下文大小与子代理写入范围都在这里 (40582f7)
- Android 壳的工程进入仓库：内核随包装在设备上启动，界面仍是同一份前端构建，agent 经 SSH 访问服务器 (42e911d)
- 手机上的页面铺到状态栏与手势条之下，安全区交给页面自己补，键盘遮挡由窗口按实测高度让出 (cc331bd)

## 变更

- 模型名的短名一律取 id 的最后一个路径段，「隐藏共同前缀」开关连同它的两个说明一并退休 (1cf3a43)
- 设置卡片按各自回答的问题重新归位：选项卡与导航卡并入对话显示页，联网并入 Agent 行为页 (c704596)
- 键位表折起并排到该页末尾，从某一行进入（chip 或搜索结果）时自动展开，指针不会落在收起的卡片上 (c704596)
- 模型编辑器里的限额与价格两块各自折起，已存的覆盖值按一下就能看到 (d66f0d5)
- 提供者的模型列表折到标题之后；一次读取或批量测试会把结果带回来时展开 (a41bba6)
- 手机端固定监听端口：页面的主题、语言与偏好存在 localStorage 里，按 origin 分区，临时端口每次启动都会丢掉它们 (4a141e5)

## 修复

- 任务区按日期归档的会话重新可列、可归档、可删除、可批量移除：删除与导出的边界改成整棵会话树 (0f7226c)
- 移除的项目不再自己回来：移除写下墓碑，启动继承的目录、会话所在目录、合并的旧列表都不再写回，重新添加才解除 (0f7226c)
- 启动不再把 home 目录当成项目（快捷方式、终端、系统默认都可能把主目录递进来） (0f7226c)
- 派发出去的会话按角色命名，伙伴窗格关掉后名字仍在 (0f7226c)
- 列表头上的 ✓ 回到原位：多选入口、全选可见、批量归档/删除，删除前的确认重新列出会话名 (159861c)
- 新建的任务落在应用自己的文件夹，不再落进当时打开的那个项目；药丸的「不使用项目」也不再被当成缺路径拒掉 (3a76f57)
- 侧栏收起时，品牌行不再压住窗口左上角的文件夹标记，标记重新可以点开资源管理器 (3927638)
- 手机上不出现配对入口：手机本身就是被配对的那台设备，没有第二块屏幕接验证码 (25d76aa)
- 页面渲染出错时显示提示并可以重开，不再留一个只能杀掉的窗口（地址与设备列表为空时尤其如此） (25d76aa)
- 带说明的设置行右边缘齐到卡片内容边，图标栏、运行中发送消息与图形渲染不再歪进去一截 (42c4eeff)

## 升级须知

- 八个插图主题包不再随包，只有 Cloudsea Gilt 与三个纯色盘随安装包发布 (d66f0d5)
- 若此前选中的正是被移除的插图包，外观会回落到默认配色；想保留就把它作为自己的主题包放回主题库 (d66f0d5)
- `hide_model_prefix` 在已存配置里仍能读，旧窗口发来的也仍被接受，只是不再起作用 (1cf3a43)

This revision brings over what belongs to this tree from the Oliver-Rui fork (`DeepSeek-Reasonix-torch`):
a sidebar of two standing groups with one drag, a dated timeline, the new-session project pill, message
times and the dispatch chip; settings are re-homed by the question they answer, and the Android shell lands.

## New

- The tree splits into 项目 and 任务, each label folding its own run with its own add entry at the right edge (159861c)
- Projects, group labels and conversation rows share one insertion line; the edge flips on the neighbour, so the line always means a move (159861c)
- The clock beside 任务列表 switches the list to a dated reading — one row per conversation, relative dates on the right (159861c)
- A new conversation names its project from the pill above the composer (search, blank project) instead of asking in the empty transcript (159861c)
- Every reply carries the time it settled, revealed on hover, switched from Settings → Conversation display → Message times (0f7226c)
- 刷新模型 re-reads an endpoint's list and fills blank aliases from its own display names; vendor marks now number 37 (0f7226c)
- The meter rail's cross-chat chip gathers the tasks this session dispatched, each with its state, each opening the session it landed on (2ad7fb3)
- Cross-project dispatch has three answers: always (the default), paired (only a pane already open in that project), never (2ad7fb3)
- Settings gains a 会话互聊 page of its own: dispatch depth, how many sessions one turn may hand to, the reference size and the subagent's write scope (40582f7)
- The Android shell's project enters the tree: the kernel ships inside the app and starts on the device, the interface is the same frontend build, and the agent reaches servers over SSH (42e911d)
- The page paints under the status bar and the gesture pill, with the safe area spent by the page itself and the keyboard's room taken from the window it was measured in (cc331bd)

## Changed

- A model reads by its id's last path segment; the hide-shared-prefix switch and its two explanations retire (1cf3a43)
- Settings cards re-home by the question each answers: the tabs card joins the display page, the web card joins the agent page (c704596)
- The keys table folds shut and stands last on its page; entering from one of its rows — a chip or a search result — opens it, so a pointer never lands on a shut card (c704596)
- The provider editor's limits and prices blocks fold behind their own headings, with a stored override one press away (d66f0d5)
- A connection's model list folds behind its heading, opening for the answer a read or a batch test brings back (a41bba6)
- The phone keeps one listening port: a page's theme, language and preferences live in origin-partitioned localStorage, which an ephemeral port would drop on every launch (4a141e5)

## Fixed

- Dated task conversations list, archive, delete and batch-remove again: the boundary is the whole sessions tree (0f7226c)
- A removed project stays removed — the tombstone outranks every unpicked source, and adding the folder again lifts it (0f7226c)
- A launch no longer takes the home directory for a project (a shortcut, a shell or the OS default hand it over) (0f7226c)
- A dispatched session is named after its role, and keeps that name after the partner's pane closes (0f7226c)
- The ✓ on the list's head is back: picking, select-all, batch archive/delete, and the delete question names the conversations again (159861c)
- A brand-new task lands in the app's own folder instead of whichever project was open, and the pill's 不使用项目 answer is no longer refused as a missing path (3a76f57)
- With the rail folded, the brand row no longer covers the folder mark in the window's corner, and the mark opens the file manager again (3927638)
- A phone draws no pairing entry: the phone is the paired device, and there is no second screen to hand a code to (25d76aa)
- A render throw shows a notice that can reopen the window instead of leaving one that can only be killed — an empty address or device list was enough to cause it (25d76aa)
- Settings rows that carry a note right-align to the card's content edge, so 图标栏, 运行中发送消息 and 图形渲染 stop reading inset (42c4eeff)

## Upgrade notes

- Eight illustrated theme packs no longer ship; only Cloudsea Gilt and the three plain palettes come with the installer (d66f0d5)
- If the active pack was one of the removed ones, the appearance falls back to the default palette; to keep it, return it to the theme library as a pack of your own (d66f0d5)
- `hide_model_prefix` still parses in a stored config and is still accepted from an older window, and nothing acts on it (1cf3a43)
