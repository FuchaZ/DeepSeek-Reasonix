本版是 FuchaZ/DeepSeek-Reasonix 的 Windows 版本，接在上游 2.61.0 之后：侧栏、对话轨与设置页重做，市场与账号移除，并修复一批界面问题。基础改动来自 @Oliver-Rui 的 torch 分支（见 [DeepSeek-Reasonix-torch](https://github.com/Oliver-Rui/DeepSeek-Reasonix-torch)），本仓库在其之上继续。

## 新增

- `reasonix web` 在 127.0.0.1 上运行时也能添加模型源，用的是本机的凭据库 (68df8bbf1)
- 派活时可以给目标会话起一个名字，同一个项目里的几个会话不再读起来像一个 (d5064179b)
- 侧栏和图标栏画同一张表里的行，两处不再各说各的，也不会把同一个入口画两次 (465da156c)
- 自定义导航栏：右键点图标栏打开，一个列表管顺序与显隐，拖动时被越过的行让位，松手才落盘 (465da156c)
- 最近排序挪进会话筛选菜单，就在全部下面：点一次最新在前，再一次最旧在前，第三次不排序 (465da156c)
- 右边缘的对话轨改成一把尺子：刻度密集、右端对齐，指到某条消息时只有那一条拉长，文字卡片贴在它左边 (465da156c)
- 项目行长出复选框，选中它就是选中这个文件夹当前显示的全部行 (465da156c)
- 设置 › 数据 里的本地文件备份仍可导出、导入与预览，分组说明跟着一起走 (fbaf9164c)
- 输入框下方的计量条上显示这个人亲手开启的轮数：中途插话与折叠摘要不算一轮 (4cb4a9e6b)
- 新设置 `peers.incoming` 决定别的会话发来的消息要不要弹授权卡 (ae2dade85)
- 会话按开启它的那一轮自动命名，不再一直是「新会话 N」 (888eb9696)
- 思考块有了自己的字重档位，调大正文字号时推理与回答仍读得出区别 (599badfd0)
- 停止按钮重画成圆环，中间的圆角方块随按钮缩放，底色不再是一团 (8bb5b9bb2)
- 展示过图片的调用卡片会自己展开，轮次收起后它所在的那组也保持展开 (d90a9a5dd)
- 预设可以声明不使用保存的记忆：后台块、自动回忆、记忆工具与规划上下文一起让开 (948fc2c02)

## 变更

- 关于页写的是本仓库的维护者与原作者，反馈入口指向本仓库 (https://github.com/FuchaZ/DeepSeek-Reasonix)
- Patina 主题的叠加底色分出明暗两级，选中态在浅色和深色下都看得见 (edce14dee)
- 「运行中展开」的思考块占满整窗，不再被六行高度截住 (14939ca16)
- 工作台的启动器铺满它所在的列，宽屏上三个按钮不再挤在左边一条 (0166c60fb)
- 打开工作台的面板滑入变柔和，不再一开头就走完三分之二 (450f2d1bc)
- 图标栏只有两种答案：工作区栏收起时出现，展开时让位；存着的旧值读回来就是收起这一种 (465da156c)
- 窗口自己打开的那个文件夹标成任务，放在项目下面一段，不再和项目混成一条 (465da156c)
- 选择本机会话挪到折叠全部旁边，项目菜单里不再有它 (465da156c)
- 插件安装的入口收成一个添加菜单：仓库地址、本地文件夹、外部服务，市场那一项随市场一起走了 (fbaf9164c)
- 设置页的每个控件回到提出那个问题的那一页 (be9120fb1)
- 记忆的正文与编辑器填满所在列，不再在半屏空白里停住 (83c8c4d63)
- 设置的每一行结尾收到行的右边缘，分段选择不再把剩下的半行留白 (dc2c90a26)
- 模型可见的设置 id 留在它自己的行上，行的折叠节名不再被页面顶替 (2e2e13ce5)

## 修复

- 后打开的面板同样拿到 provider 授权，一个项目能加模型、另一个不能的情况不再出现 (7a19686ad)
- 任务文件夹的复选框与键盘焦点在各折叠状态下都能落回一个真的能按的控件 (465da156c)
- 权限与安全里的项目列表不再被裁成一窄条，重叠的设置导航也让开 (d0a0c2212)
- 计量条上的轮数与旁边的标签对齐在同一行，不再掉到下一行 (8991792ba)
- 扩展范围的药丸从行的左缘打开列表，不再从右边缘弹到远处 (c0a46f934)
- 设置页窗口栏的最小化、最大化、关闭重新能按，此前按下去变成拖动窗口 (4ec6d4410)
- 项目药丸的下拉箭头回到标签同一行，带「N 项例外」徽章的行不再错位 (4ec6d4410)
- 设置页里「用量」「扩展」两行重新读得出自己是当前页 (282ba8507)
- 计量条上的卡组芯片在窄栏里先让位，不再越出右边缘 (51fa5d1a5)
- 调大界面的字重后，加粗强调不再与正文同色同重 (45d3e3fd7)
- 进行到一半的步骤按手头的序号显示，不再画一个转动的记号 (a4cc9151a)
- 拖动查看图片后松手会把预览关掉；现在只有落在背景上的那次点击才会关 (18e08c5c4)
- 收起侧栏后点标题栏的文件夹图标打不开资源管理器：收起的侧栏不再残留一块拖拽区盖住它 (7cf425f41)

## 移除

- 关于里的社区与贡献者、赞助：QQ 群、Discord、议题入口、贡献者名单、收款码，连同它们的样式、图片与英文词条 (465da156c)
- 抖音入口（账号、复制按钮、二维码）一并移除 (465da156c)
- 最近页：最近现在是一种排序，不再是一个页面 (465da156c)
- 社区市场整体移除：浏览、详情、安装确认、发布、我的发布、投票，以及通向它们的登录提示 (fbaf9164c)
- 账号本身也移除：关于页的登录、登录后的云端备份、窗口顶部的在线状态点 (fbaf9164c)
- 只有登录才能到达的设置行一并移除 (c555b5c52)

## 升级须知

- 本版 Windows 安装包未做代码签名，首次运行可能被 SmartScreen 拦下，选择「仍要运行」即可 (https://github.com/FuchaZ/DeepSeek-Reasonix)
- 软件内的更新检查仍指向原项目的发布清单，装了本版后版本面板可能提示升级到原项目的新版；是否升级由你决定 (https://github.com/FuchaZ/DeepSeek-Reasonix)
- 存过「图标栏常显」的机器读回来是「收起时显示」，因为常显会把同样的入口在屏幕上画两次 (465da156c)
- 市场没了，已经装好的插件照常工作；新插件仍可从仓库地址、本地文件夹、外部服务或备份文件装进来 (fbaf9164c)
- 云端备份随账号一起移除，先前传上去的备份不再能从界面里取回；本地文件备份不受影响 (fbaf9164c)
- 别的会话发来的消息要不要弹授权卡，从此由 `peers.incoming` 决定：默认的 `dispatch` 只放行已配对的会话，要接住任意会话就把 `incoming` 设成 `always` (ae2dade85)

<!-- lang:en -->

This is FuchaZ/DeepSeek-Reasonix's Windows build after upstream 2.61.0: the sidebar, rail and settings pages are reworked, the market and account are gone, and defects are fixed. The base work comes from @Oliver-Rui's [DeepSeek-Reasonix-torch](https://github.com/Oliver-Rui/DeepSeek-Reasonix-torch) branch.

## New

- `reasonix web` on 127.0.0.1 can add a model source, using this machine's own credential store (68df8bbf1)
- A dispatch may name the session it opens, so several sessions in one project do not read as one (d5064179b)
- The sidebar and the icon bar draw the rows of one table, so the two can no longer disagree or offer one destination twice (465da156c)
- 自定义导航栏 opens on a right click on the bar: one list orders the rows and hides them, crossed rows give way while dragging, and the order is written on release (465da156c)
- 最近 ordering moved into the session filter menu, under 全部: newest first, then oldest first, then unsorted, with an arrow that always says which (465da156c)
- The conversation rail on the right edge is a ruler: dense ticks sharing one right edge, and only the pointed tick stretches, with its text in a card to its left (465da156c)
- A project row grows a checkbox that picks every row the folder shows (465da156c)
- The local file backup under 设置 › 数据 still exports, imports and previews, with its group notes beside it (fbaf9164c)
- The meter rail under the composer carries the turns this person started, where a mid-turn steer and a fold digest do not count (4cb4a9e6b)
- A new `peers.incoming` setting decides whether a message from another session shows the approval card (ae2dade85)
- A session is named from the turn that opened it instead of staying "new session N" (888eb9696)
- Thought has its own weight step, so reasoning and answer stay distinct when body weight is raised (599badfd0)
- The stop control is drawn as a ring around a rounded square that scales with the button, with a transparent ground (8bb5b9bb2)
- A call that showed the model a picture opens itself, and its group stays open once the turn folds (d90a9a5dd)
- A preset may withhold saved memory: the background block, automatic recall, the memory tools and the planner context all step aside (948fc2c02)

## Changed

- 关于 names this repository's maintainer and the original author, and the feedback entry points here (https://github.com/FuchaZ/DeepSeek-Reasonix)
- Patina's overlay gains its own step, so selection stays visible in light and dark (edce14dee)
- "Open while running" lets the live thought use the whole window instead of six lines (14939ca16)
- The workbench launcher fills its column, so the three start buttons no longer sit in a strip on the left (0166c60fb)
- The workbench panel slides in gently instead of covering two thirds of the travel at once (450f2d1bc)
- The icon bar has two answers: it appears while the workspace column is shut and gives way while it is open; a stored "always" reads back as the first (465da156c)
- The folder the window itself opened in is announced as 任务 below the projects instead of reading as one of them (465da156c)
- 选择本机会话 moves beside fold-all and no longer sits in the project menu (465da156c)
- Every way into the extensions list sits behind one add menu — a repository address, a local folder, a connected service — with the market entry gone with the market (fbaf9164c)
- Each settings control is filed on the page that asks its question (be9120fb1)
- The memory body and editor fill their column (83c8c4d63)
- A row's segmented control ends at the row's edge instead of leaving the rest of the row blank (dc2c90a26)
- The model-facing setting ids stay on their rows, and the section a row declares is not replaced by its page (2e2e13ce5)

## Fixed

- A pane opened later gets the provider grant too (7a19686ad)
- The 任务 folder's checkbox and keyboard focus land on a control that can actually be pressed at every fold state (465da156c)
- The project list under 权限与安全 is no longer clipped to a narrow strip (d0a0c2212)
- The turn count sits on the meter rail's own text line instead of dropping to a lower row (8991792ba)
- The scope pill opens its list from the row's left edge instead of its right (c0a46f934)
- The settings windowbar's minimise, maximise and close work again instead of dragging the window (4ec6d4410)
- The project pill's dropdown arrow stays on its label's line, and rows carrying an "N exceptions" badge no longer misalign (4ec6d4410)
- The 用量 and 扩展 rows read as the current settings page again (282ba8507)
- A deck chip on the meter rail yields before leaving the rail's right edge (51fa5d1a5)
- Emphasis keeps its own ink when body weight is raised (45d3e3fd7)
- A step in hand shows its ordinal instead of a turning mark (a4cc9151a)
- A pan on an image no longer closes the preview; only a press on the backdrop does (18e08c5c4)
- With the workspace column shut, the chrome's folder mark could not open Explorer: the folded rail no longer leaves a drag region over it (7cf425f41)

## Removed

- 社区与贡献者 and 赞助 in 关于: the QQ group, Discord, the issues entry, the contributor list, the PayPal, WeChat and Alipay codes, with their styles, images and English strings (465da156c)
- The 抖音 entry (account id, copy button, QR code), removed in the same round (465da156c)
- The 最近 page: 最近 is an ordering now, not a page (465da156c)
- The community market is gone: browse, detail, install confirmation, publishing, your own packages, voting, and the sign-in prompts that led to them (fbaf9164c)
- So is the account: sign-in on the 关于 page, the cloud backup behind it, and the presence dot in the window chrome (fbaf9164c)
- The settings rows only a signed-in account could reach (c555b5c52)

## Upgrade notes

- The Windows installer is unsigned, so SmartScreen may hold the first launch; choose to run it anyway (https://github.com/FuchaZ/DeepSeek-Reasonix)
- The update check still points at the original project's catalog, so the versions panel may offer its newer build (https://github.com/FuchaZ/DeepSeek-Reasonix)
- A stored "always show the icon bar" reads back as "while the column is shut", because always-on drew the entries twice (465da156c)
- The market is gone, so installed plugins keep working, and a new one still arrives from a repository address, a local folder, a connected service or a backup file (fbaf9164c)
- The cloud backup went with the account, so backups uploaded earlier cannot be fetched any more; the local file backup is unaffected (fbaf9164c)
- Whether a message from another session shows the approval card is decided by `peers.incoming`: `dispatch` takes only a paired session, `always` any (ae2dade85)
