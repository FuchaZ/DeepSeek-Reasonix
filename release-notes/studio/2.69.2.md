本版把转录里成串的工具调用收成一行：连续看过几张图读作「查看图片 N 张」，连续跑过几条命令读作「运行命令 N 条」。此前每一次调用各占一张卡，四次读取就是四份图标、标题和耗时；「执行过程」也不再遇到图片就无视折叠设置自己展开。

## 变更

- 连续的 `view_image` 合成一行「查看图片 N 张」，N 张缩略图并排，每张仍带自己的文件路径，点开仍是大图 (ff0715cfc)
- 连续的 `bash` 合成一行「运行命令 N 条」，每条命令各占一行，点开能看完整命令和它的输出，也能把结果带到末尾 (ff0715cfc)
- 只有结束的调用参与合并：失败的要显示退出码，运行中的是读者正在等的那条，后台任务保留自己的状态入口，三者都独立成行 (ff0715cfc)
- 一次调用不成组：单张图、单条命令仍是原来的卡片，不额外加一层标题 (ff0715cfc)
- 「执行过程」此前遇到图片会无视折叠设置强行展开，现在按设置来；收起时在组头上写明它持有什么 (ff0715cfc)
- 一条 shell 命令的行不再裁成 96 字符的半句话，改说它运行了一条命令；完整命令在展开后的输入里 (5ecafc8df)

## 修复

- 正在运行的调用换了会话再回来，计时不再从头开始 (d1e65859e)

This release gathers runs of tool calls into one line: several pictures in a row read as "Viewed N images", several commands in a row as "Ran N commands". Before this each call had a card of its own; the execution group also stops opening itself for a picture, against the reader's folding preference.

## Changed

- Consecutive `view_image` calls become one "Viewed N images" row; the thumbnails sit side by side, each still naming its own file, and each still opens full size (ff0715cfc)
- Consecutive `bash` calls become one "Ran N commands" row; each command is its own line and opens to the whole command and its output (ff0715cfc)
- Only finished calls take part: a failed one keeps the row that shows its exit status, a running one is what the reader is waiting on, and a background start keeps the row that leads to its output (ff0715cfc)
- A single call is not a group: one picture or one command stays the card it was, with no heading above it (ff0715cfc)
- The execution group obeys the reader's folding preference; folded, it says on its own line what it holds (ff0715cfc)
- A shell row no longer shows the command clipped at 96 characters; it says a command ran, and the whole command is in the body (5ecafc8df)

## Fixed

- A running call's timer no longer restarts when a session switch draws the pane again (d1e65859e)

## Upgrade notes

- Installing 2.69.2 over 2.69.1 replaces it; the installer carries its version in the name: `ReasonixStudio-windows-amd64-2.69.2-installer.exe` (https://github.com/FuchaZ/DeepSeek-Reasonix/releases)
- The installer is unsigned, so the first launch needs the system prompt allowed (https://github.com/FuchaZ/DeepSeek-Reasonix/releases)
